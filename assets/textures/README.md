# Generated game textures

Created with the built-in ImageGen tool for this project, September 2026.
No third-party photograph or existing game texture was supplied as reference.

- panel_facade.png: orthographic four-by-four grid of Soviet concrete panels,
  windows with varied frames and curtains, diffuse neutral light, no sky or ground.
- asphalt.png: overhead charcoal asphalt, fine aggregate and restrained wear,
  repeatable surface without markings, objects, perspective or directional shadows.

Both textures are connected in CityMaterials and sampled in world coordinates
with mipmap filtering. Small edge variations are possible in generated textures.
