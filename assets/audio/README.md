# Original radio loop

radio_evening.wav was synthesized for this project with NumPy: 88 BPM,
electric-key sine harmonics, Am7 / Fmaj7 / Cmaj7 / G6, bass and quiet noise
percussion. It contains no sampled third-party recording. Mono PCM, 22050 Hz.
The game loops it and applies the saved radio/master volume settings.
