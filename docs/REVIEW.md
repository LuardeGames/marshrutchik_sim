# Проверка доработки города и транспорта

Проверено в Godot 4.6.stable.official.89cea1439.

- Импорт проекта и регистрация GDScript-классов: без ошибок.
- Smoke: **30 PASS / 0 FAIL**.
- Оба автобуса, все 6 остановок: **66 PASS / 0 FAIL**.
- Реальный OpenGL Compatibility-рендер (Mesa llvmpipe, 1280×720): меню,
  гараж, город, газель и пазик просмотрены; ошибки шейдеров не обнаружены.
- Исправлены пересвет, наложение панелей гаража, размер предпросмотров и
  отсутствующие emoji-глифы.
- `git diff --check`: без ошибок.

Маршрутный тест телепортирует автобус между остановками. Он проверяет
реальные зоны, ходьбу и посадку NPC, блокировку дверей и движения,
высадку на конечной, результат, защиту выплат и переход в гараж.
Он не доказывает удобство каждого поворота при ручном вождении.

В окружении проверки есть предупреждение о неподдерживаемом VSync в
виртуальном дисплее и предупреждение ObjectDB о ресурсах при завершении
тестового процесса. Ошибок выполнения GDScript нет. FPS этого программного
рендера не используется как обещание производительности на устройствах.

Не проверены Web-экспорт, мобильные браузеры и настоящий Yandex Games SDK.
Реклама скрыта, SDK остаётся локальным адаптером. Стилизация моделей
намеренно геометрическая; это не фотореалистичные сканированные машины.
