# Release plan: Маршрутчик Simulator

Документ фиксирует границу первой версии для Web/mobile и Яндекс Игр. После
закрытия обязательных пунктов игру нужно отдавать на ручной плейтест, а не
продолжать бесконечный полиш.

## Уже закрыто

- законченный цикл: меню → рейс → 6 остановок → результаты → гараж;
- 3 маршрута: №47, №12 и №5; два последних открываются после 1 и 3 рейсов;
- ГАЗель и ПАЗ с разными параметрами;
- 7 архетипов пассажиров и посадка/высадка;
- 15 случайных событий, комфорт, столкновения и состояние машины;
- деньги, 5 веток улучшений по 3 уровня и ремонт;
- ежедневный модификатор рейса;
- мини-карта, трафик, светофоры, пауза и touch-управление;
- атомарное сохранение с резервной копией;
- headless smoke/full-route/regression checks.

## Осталось до публичного Web-билда

1. Запустить `tests/run_checks.sh` через установленный Godot 4.6 и исправить
   все реальные ошибки, если они появятся после импорта.
2. Сделать Web export и проверить загрузку в Chrome и Яндекс Browser.
3. Проверить на физических телефонах: первый запуск, поворот, touch-зоны,
   пауза, посадка, результаты и восстановление сохранения.
4. Проверить настоящий Yandex Games SDK через `PlatformService`: cloud save,
   rewarded video ×2, interstitial, GameplayAPI, LoadingAPI и leaderboard.
   Локальные заглушки должны остаться только для запуска вне Яндекс Игр.
   Analytics SDK-события остаются отдельным следующим слоем после первого
   плейтеста.
5. Провести ручной плейтест минимум на 5 рейсов и проверить, что первый рейс
   понятен без чтения README, а второй имеет причину начаться.

## Release gate

Публикуем, когда одновременно выполнены все условия:

- чистый импорт и все автоматические проверки проходят;
- Web-билд загружается без ошибок;
- нет softlock при посадке, паузе, аварии и завершении рейса;
- все 3 маршрута можно открыть и пройти;
- сохранения переживают перезапуск;
- мобильное управление playable;
- SDK-реклама не показывается чаще заданного лимита и не ломает награду;
- после ручного плейтеста нет явной визуальной или геймплейной поломки.

Не блокируют первую публикацию: большая сюжетная кампания, десятки машин,
сложная кастомизация, уникальная модель каждого пассажира и фотореалистичная
графика.
