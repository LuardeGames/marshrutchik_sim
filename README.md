# Маршрутчик Simulator

Браузерная 3D arcade-driving comedy simulator игра на Godot 4 (GDScript).
Вы — водитель стереотипной маршрутки в провинциальном городе СНГ: возите
пассажиров по кольцевому маршруту, собираете оплату, переживаете мемные
ситуации в салоне, соревнуетесь с конкурентом-маршрутчиком за пассажиров и
прокачиваете машину между рейсами.

Игровой цикл: **меню → на линию → маршрут (6 остановок) → посадка/высадка →
события → конечная → результаты → гараж/апгрейды → следующий рейс.**

## Управление

**Desktop (клавиатура):**
| Действие | Клавиши |
|---|---|
| Газ | `W` / `↑` |
| Тормоз / задний ход | `S` / `↓` |
| Руль | `A/D` или `←/→` |
| Ручник | `Space` |
| Двери | `E` |
| Меню/пауза | кнопка ☰ в углу HUD |

**Mobile (landscape, touch):** крупные экранные кнопки — руль влево/вправо,
газ, тормоз, двери. Появляются автоматически, если устройство поддерживает
touch (`DisplayServer.is_touchscreen_available()`).

При «сдаче с крупной купюры» и других событиях появляются крупные кнопки
выбора — управляются мышью/тапом на любой платформе.

## Структура проекта

```
scenes/
  main_menu/      — главное меню
  gameplay/        — сцена рейса (мир строится процедурно в рантайме)
  garage/          — гараж/апгрейды
  ui/              — HUD (в коде, инстансится в gameplay)
scripts/
  autoload/        — GameManager, SaveManager, AudioManager, EconomyManager,
                      PlatformService, EventBus, InputState (singletons)
  vehicle/         — VehicleController (arcade-физика), CameraRig,
                      VehicleDefinition/Catalog (данные машин)
  passengers/       — Passenger (визуальный NPC), PassengerManager,
                      PassengerArchetype/Catalog (архетипы пассажиров)
  route/           — RouteDefinition (путь + остановки), RouteManager,
                      StopArea
  events/          — GameEvent (Resource), EventCatalog, RandomEventManager
  economy/         — UpgradeData (Resource), UpgradeCatalog
  ai/              — CompetitorAI (конкурент-маршрутчик)
  world/           — WorldBuilder (процедурная генерация города),
                      TrafficLightProp, TrafficDummy
  ui/              — HUD, MainMenu, Garage, UITheme (стилизация)
  game/             — Gameplay (оркестрация сцены рейса)
tests/
  smoke_test.gd    — headless smoke-test
assets/
  vehicles/        — маршрутки (Kenney Car Kit, CC0, см. ниже)
  city/            — здания/киоски (Kenney City Kit companion set, CC0)
```

Системы общаются в основном через сигналы `EventBus` (слабая связанность),
конфигурация вынесена в `Resource`-классы (`UpgradeData`, `GameEvent`,
`PassengerArchetype`, `VehicleDefinition`) и статические каталоги.

Дорога, разметка, бордюры, тротуары, светофоры, панельные дома, деревья —
**процедурная low-poly геометрия**, собранная в рантайме из примитивов
Godot (BoxMesh, CylinderMesh, SphereMesh, MultiMesh для деревьев).

Маршрутки и небольшие здания/киоски/рынок — готовые low-poly `.glb`-модели
из **Kenney Car Kit** и его City-компаньона (`assets/vehicles`,
`assets/city`; лицензия CC0 — можно использовать без атрибуции, но она всё
равно указана здесь: [kenney.nl](https://kenney.nl)). Кузов маршрутки
перекрашивается в код через плоский `StandardMaterial3D` (у моделей общая
текстура-палитра на весь кит, поэтому обычный тон через `albedo_color`
оставлял полосатую раскраску скорой помощи/фургона — исправлено заменой
материала кузова/дверей на однотонный, без текстуры). Высокие дома
(жилые кварталы, поликлиника, вокзал, центр) остаются процедурными боксами
с "окнами" — под них в этом ките подходящих высоких моделей нет.

## Как запустить

1. Установите Godot 4.6+ (движок, GDScript).
2. Откройте папку проекта в Godot (`project.godot`) или запустите из
   консоли:
   ```bash
   godot4 --path .
   ```
3. Нажмите Play. Главная сцена — `scenes/main_menu/main_menu.tscn`.

## Headless smoke-test

```bash
godot4 --headless --path . --script res://tests/smoke_test.gd
```

Проверяет: загрузку проекта/сцен, наличие 6 остановок на маршруте,
корректную длину маршрута, save/load, покупку апгрейда, наличие ≥5 треков
апгрейдов с ≥3 уровнями, ≥2 машины, сборку мира и спавн машины/конкурента/
пассажиров, программное завершение рейса и расчёт результата, а также
fallback-методы `PlatformService`. Скрипт завершается кодом `0` при полном
успехе и `1` при любом провале проверки (см. вывод `[PASS]`/`[FAIL]`).

## Сборка Web-версии

1. Установите Web export templates (Editor → Manage Export Templates, либо
   `godot4 --headless --install-android-build-template` для Android — для
   Web используйте пункт «Web» в менеджере шаблонов экспорта).
2. В проекте уже настроен `export_presets.cfg` (пресет `Web`).
3. Экспорт из консоли:
   ```bash
   godot4 --headless --path . --export-release "Web" build/web/index.html
   ```
4. Раздайте содержимое `build/web/` как статику (или загрузите в Яндекс
   Игры как ZIP по их требованиям).

Игра не использует файловую систему напрямую (только `user://` для
сохранений через `SaveManager`), клавиатуру/мышь/touch читает через
единый `InputState`, поэтому готова к Web-экспорту без доработок логики.

## Реализованные системы (acceptance checklist)

- ✅ Главное меню (НА ЛИНИЮ / ГАРАЖ / НАСТРОЙКИ), деньги и статистика на
  экране.
- ✅ Полноценная арcade-физика маршрутки (инерция, руль, ручник, крен
  кузова, столкновения, ограничение скорости) — `VehicleController`.
- ✅ Плавная follow-камера от третьего лица с shake при ударах —
  `CameraRig`.
- ✅ Процедурная карта: кольцевой маршрут ~2.4 км, повороты, перекрёстки,
  имитация светофоров, декоративный встречный трафик, 6 тематических
  районов (спальный, рынок, поликлиника, центр, вокзал, конечная/депо) +
  generic filler-застройка и деревья через `MultiMesh`.
- ✅ 6 остановок с маркерами/павильонами, детекцией зоны и качеством
  парковки (хорошая/далеко) — `StopArea`, `RouteManager`.
- ✅ Пассажиры: 5 архетипов, случайное количество на остановке, посадка/
  высадка с ходьбой к двери, отдельные destination_stop/fare/mood —
  `PassengerManager`, `PassengerCatalog`.
- ✅ Комфорт (0–100%), снижается от резких манёвров/столкновений, слегка
  восстанавливается при спокойной езде, влияет на бонус в конце рейса.
- ✅ AI-конкурент, идущий по тому же маршруту и забирающий часть ожидающих
  пассажиров, если приезжает раньше — `CompetitorAI`.
- ✅ 15 data-driven комедийных событий (`EventCatalog`) + отдельный
  мини-ивент «дать сдачу» с 2-3 вариантами ответа и бонусом за точность.
- ✅ Экономика: тариф/остановочный бонус/комфорт-бонус/штрафы, экран
  результатов с рейтингом 1-3 звезды.
- ✅ Meta-progression: деньги сохраняются в `user://savegame.json`, гараж
  с 5 треками апгрейдов (двигатель/тормоза/подвеска/вместимость/двери) по
  3 уровня каждый, растущая стоимость.
- ✅ 2 машины (стартовая и разблокируемая за деньги современный
  микроавтобус) с разными характеристиками и визуалом.
- ✅ Desktop + mobile touch controls, адаптивный landscape UI, стилизованные
  `StyleBoxFlat`-панели вместо дефолтных Control.
- ✅ Полностью процедурная звуковая система (`AudioManager`,
  `AudioStreamGenerator`) — без внешних аудиофайлов: двигатель, торможение,
  столкновение, двери, посадка, деньги, UI click, успешная остановка,
  завершение рейса.
- ✅ Game feel: camera shake, крен/питч кузова, brake/headlights, пыль и
  выхлоп (`GPUParticles3D`), реакция пассажиров на рывки, звук + подсветка
  при покупке апгрейда, плавные UI-переходы (tween).
- ✅ `PlatformService` — адаптер для Yandex Games SDK (interstitial/
  rewarded/cloud save/leaderboard) с локальным fallback, независимый от
  игровой логики.
- ✅ Headless smoke-test (`tests/smoke_test.gd`), проходит полностью.
